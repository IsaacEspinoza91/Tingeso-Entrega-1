		Servicios

Cliente
-	Obtener todos los clientes: GetClientes()
-	Obtener cliente por id: GetClienteById(id)
-	Obtener cliente por rut: GetClienteByRut(rut)
-	Guardar Cliente nuevo: SaveCliente( Cliente)
-	Actualizar Cliente:    UpdateCliente(id, Cliente )
-	Eliminar Cliente por id:  DeleteCliente( id)

(Se realizaron las mismas operaciones para todas las entidades de la base de datos)

- DetalleComprobanteEntity

GET, Obtiene todos los detalles (No muestra datos de entidad comprobante para evitar recursion en json): localhost:8080/detalleComprobantes/

GET, Obtiene todos los detalles de un comprobante segun su id:  localhost:8080/detalleComprobantes/comprobante/4

GET, Obtiene un detalle segun su id compuesta:    localhost:8080/detalleComprobantes/detalle_especifico?id_detalle=3&id_comprobante=4

POST, Crea detalle: localhost:8080/detalleComprobantes?id_comprobante=4
{

  "descuentoGrupo": 3000,

  "montoIva": 2850,

    "nombre": "w1",

    "descuentoEspecial": 0,
