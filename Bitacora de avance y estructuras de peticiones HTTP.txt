Cliente

- DetalleComprobanteEntity

GET, Obtiene todos los detalles (No muestra datos de entidad comprobante para evitar recursion en json): localhost:8080/detalleComprobantes/

GET, Obtiene un detalle segun su id compuesta:    localhost:8080/detalleComprobantes/detalle_especifico?id_detalle=3&id_comprobante=4

GET, Obtiene un detalle segun id de cliente e id de comprobante:   localhost:8080/detalleComprobantes?id_cliente=2&id_comprobante=1

GET, Obtiene todos los detalles de un cliente segun id:  localhost:8080/detalleComprobantes/cliente/2

RackSemanal
- Obtener las reservas de una semana segun el dia por nombre (lunes, martes, ...): localhost:8080/rackSemanal/?semana=0
El valor indica el numero de semana: 0->semana actual, 1-> prox semana, 2-> prox 2 semana, -1-> semana anterior.
En caso de no indicar el valor, retorna la semana actual    localhost:8080/rackSemanal/
