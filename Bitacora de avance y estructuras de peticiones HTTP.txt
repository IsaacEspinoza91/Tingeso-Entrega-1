- ComprobanteEntity 
Consideraciones:
	Los Detalles Comprobantes se crean automaticamente al crear el Comprobante. Estos se asignan a los clientes previamente existentes en la lista de integrantes de la Reserva. Por lo que si no estan anteriormente asignados, no se podrá crear el comprobante
	Solo se puede crear un comprobante por reserva

GET, Obtiene los comprobantes: localhost:8080/comprobantes/

GET, Obtiene comprobante por id: localhost:8080/comprobantes/2

POST, Crea comprobante: localhost:8080/comprobantes?id_reserva=2		FK en URL
{
    "pagado": true,
    "total": 2502
}

PUT, update de datos de comprobante por id (no cambio de reseva): localhost:8080/comprobantes/1
{
    "pagado": false,
    "total": 2502
}

PUT, update de reserva (id) en un comprobante por id: localhost:8080/comprobantes/3/reserva?id_reserva=4

DELETE, eliminar comprobante por id (no elimina reserva): localhost:8080/comprobantes/1

Extra:
POST, craer Comprobante y los Detalles asociados. Necesita que los integrantes ya existan en la lista de integrantes de la reserva (Se indica si el dia es feriado o no):
localhost:8080/comprobantes/segun-reserva/1?feriado=false&descuento_extra=0

CONFIRMACION DE FUNCIONALIDADES EN FRONT
Calendario CHECK
Reportes CHECK
Cliente:
	C: Crear cliente CHECK
	R: Lista clientes. Buscar por ID, RUT, Nombre Apellido   CHECK
	U: Actualizacion cliente CHECK
	D: Eliminar cliente CHECK   (No se actualiza pantalla automaticamente. Algo falla, debería hacerlo) (No borrar clientes para no perder info relacionada)

Planes:
	C: Crear plan CHECK
	R: Lista planes y buscar segun id CHECK
	U: Actualizar plan CHECK
	D: Eliminar plan CHECK

Karts:
	C: Crear kart CHECK
	R: Lista karts y buscar por id CHECK
	U: Actulizar plan CHECK
	D: Eliminar plan CHECK

Reservas:
	C: Crear reserva en horarios validos (condicion) CHECK
	R: Lista reservas y buscar por id y cliente CHECK
	U: Update reserva, consideran cambio de hora final cuando se cambia el plan o la hora de incio (No se actualiza pantalla automaticamente) CHECK
	  Solo se puede agregar integrantes cuando todavia no se cumple el maximo de grupo CHECK
	  Al actualizar total de integrantes. Se reinicia la lista de integrantes (Caso disminuir cantidad) CHECK
	  Se puede agregar y quitar integrantes de la reserva CHECK
	D: Eliminar reserva con y sin integrantes CHECK
	  Solo se elimina reserva si no tiene un comprobante asociado

Comprobantes:
	C: Crea el comprobante con los detalles CHECK
	  No se crea comprobante si no están todos los integrantes agregados
	R: Lista de comprobantes y sus detalles. Busca por id  CHECK
	U: Actualizacion de pagado y total de comprobante   CHECK
	   En detalles:  Se actualiza el porcentaje los porcentajes de descuento y el valor de descuento extra. Los demas valores se calculan automaticamente por lo que no tiene sentido poder cambiarlos manualmente.
	D: Eliminar comprobante con y sin detalles CHECK
	   En detalle: No se puede eliminar un detalle en particular
